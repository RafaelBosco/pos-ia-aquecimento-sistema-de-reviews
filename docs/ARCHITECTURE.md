# Arquitetura do Projeto

## Front-End
Vamos utilizar as seguintes bibliotecas:
- Typescript: desenvolvimento com tipagem
- Next.js: framework para criação e gestão de interfaces
- React.js: Criação e componentização de interfaces
- Biome Validação/formatação/correção de código (lint)
- TailwindCSS: Estilização
- Date-FNS: Manipulação e formatação de datas/horas
- Shadcn: Componentização base (design system)
- React Query: Criação e gestão de query para ler dados da API e mutations para alterar dados.

## Back-End
Vamos utilizar as seguintes bibliotecas:
- Typescript: desenvolvimento com tipagem
- Next.js: framework para criação de APIs
- Crypto: geração de salt + hash das senhas
- Mastra.ai: Criação e customização de agentes internos
- TRPC: Gestão de end-points

## Banco de Dados
Supabase: PostgresQL

## Infraestrutura
Vercel: Hospedar tanto servidor (API) quanto cliente (SPA - Single Page Application)

## Automação
N8N: criação de fluxos automatizados
