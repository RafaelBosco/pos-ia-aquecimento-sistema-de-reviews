# SDD (Spec-Driven Development)

[Link da aula](https://app.codersuniversity.com.br/curso/projeto-pratico/154593/892315)

O SDD (Spec-Driven Development) é uma abordagem de desenvolvimento de software que se concentra na definição de especificações detalhadas antes da implementação.

Ele busca garantir que o desenvolvimento siga rigorosamente as especificações definidas, minimizando ambiguidades e erros durante a implementação.

## Spec/prompt checklist:
1. Contexto
2. Objetivo
3. Requisitos Funcionais
4. Requisitos Não Funcionais
5. Edge cases
6. Regras
7. Critérios de aceitação/validação
8. Restrições/Limitações
9. Dependências
